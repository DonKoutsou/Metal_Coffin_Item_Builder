# Metal Coffin Item Builder

This is a tool ment to be used to create mods for Metal Coffin. The use of this tool is to provide a user interface when creating or manipulating stats of items in the game, like their prices, the cards they provide etc...

## Packer
The unpacker/packer will be found here, this can be used to unpack the game files and afterwards pack your changes in a mod that can be used in the game.
[Metal Coffin Mod Packer](https://github.com/DonKoutsou/MetalCoffin-Mod-Packer)

## Other Tools
The unpacked files can be manually modified or the Official tools can be used instead.
* [Card Builder](https://github.com/DonKoutsou/Metal_Coffin_Card_Builder)
* [Dialogue Editor](https://github.com/DonKoutsou/Metal_Coffin_Dialogue_Editor)
* [Captain Creator](https://github.com/DonKoutsou/Metal_Coffin_Dialogue_Editor)
